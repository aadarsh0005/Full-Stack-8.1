# React Login Form (useState)

This project is a simple **Login Form** built using **React** and basic state management with the `useState` hook.

## ✅ Features
- Captures **username** and **password**
- Validates for empty fields
- Displays an inline **error message**
- Logs entered credentials to the browser console
- Simple, clean UI

---

## 🚀 How to Run the Project

### 1. Install Dependencies
```
npm install
```

### 2. Start Development Server
```
npm start
```

The app will automatically open in your browser at:
```
http://localhost:3000
```
